Animate

Overview

To get fade out effect just set:

animateOut: 'fadeOut'

fadeOut is the only animation included by Owl Carousel. Add your own CSS animations or use Animate.css for more effects.

Important

Animate effects work only with items:1 and in browsers that support CSS animations and transitions. They apply to programmatic navigation such as dots, arrows, autoplay, and API calls. During drag or swipe, Owl follows the pointer directly and intentionally skips these effects.

How to use additional animations from Animate.css

Visit the Animate.css website to browse the available animations and usage documentation. Owl's traditional unprefixed animation option values work with the Animate.css 4 compatibility build.

  1. Include the pinned compatibility stylesheet from jsDelivr in the page header:
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/animate.css@4.1.1/animate.compat.css">
  1. Set animateOut and animateIn to class names provided by that stylesheet.

The compatibility build uses familiar unprefixed names such as slideOutDown and flipInX. For the standard prefixed build, load:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/animate.css@4.1.1/animate.min.css">

Then use names such as animate__slideOutDown and animate__flipInX.

$('.custom1').owlCarousel({
	animateOut: 'slideOutDown',
	animateIn: 'flipInX',
	items:1,
	margin:30,
	stagePadding:30,
	smartSpeed:450
});

How does it work?

Before animation starts three classes are added to each item:

  • .animated — added to both incoming and outgoing items; Owl core includes its timing styles.
  • .owl-animated-out — added only to the outgoing item and can be used to control its stacking order.
  • .owl-animated-in — added only to the incoming item and can be used to control its stacking order.
  • The configured animateOut class — added only to the outgoing item.
  • The configured animateIn class — added only to the incoming item.

Part of owl.carousel.css:

/* Feel free to change duration  */

.animated {
  -webkit-animation-duration: 1000ms;
  animation-duration: 1000ms;
  -webkit-animation-fill-mode: both;
  animation-fill-mode: both;
}

/* .owl-animated-out - only for current item */
/* This is very important class. Use z-index if you want move Out item above In item */

.owl-animated-out{
  z-index: 1
}

/* .owl-animated-in - only for upcoming item */
/* This is very important class. Use z-index if you want move In item above Out item */

.owl-animated-in{
  z-index: 0
}

/* .fadeOut is included in owl.carousel.css: */

.fadeOut {
  -webkit-animation-name: fadeOut;
  animation-name: fadeOut;
}

@-webkit-keyframes fadeOut {
  0% {
    opacity: 1;
  }
  100% {
    opacity: 0;
  }
}

@keyframes fadeOut {
  0% {
    opacity: 1;
  }
  100% {
    opacity: 0;
  }
}
