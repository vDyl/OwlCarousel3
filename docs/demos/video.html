Video

Overview

Built-in video support

The video plugin provides automatic thumbnails, a play button, and embedded playback for YouTube and Vimeo. Enable it with:

video: true

Add an element with the owl-video class and a direct YouTube or Vimeo page URL:

<a class="owl-video" href="https://www.youtube.com/watch?v=VIDEO_ID"></a>

The element does not have to be an <a>. When another element is used, identify the video with data-youtube-id="VIDEO_ID" or data-vimeo-id="VIDEO_ID".

Other video players

Carousel items can contain any HTML, so you can also add a native HTML5 <video> element, an iframe from another provider, or a third-party player component. Do not give these custom players the owl-video class: Owl Carousel will treat them as ordinary slide content and will not create their thumbnail or control playback.

For a custom player, your application is responsible for its markup, responsive sizing, controls, autoplay permissions, accessibility, and stopping playback when the slide changes. Also follow the embedding, referrer, privacy, and Content Security Policy requirements of the selected provider.

Serve pages over HTTP or HTTPS when using embedded players. Opening an HTML file directly with file:// can prevent YouTube from receiving the referrer information required to identify the embedding page.

Additional video options:

videoWidth: false, // Default false; Type: Boolean/Number
videoHeight: false, // Default false; Type: Boolean/Number

Setup

	$('.owl-carousel').owlCarousel({
		items:1,
		merge:true,
		loop:true,
		margin:10,
		video:true,
		lazyLoad:true,
		center:true,
		responsive:{
			480:{
				items:2
			},
			600:{
				items:4
			}
		}
	})

html

<div class="owl-carousel owl-theme">
	<div class="item-video" data-merge="3"><a class="owl-video" href="https://vimeo.com/23924346"></a></div>
	<div class="item-video" data-merge="1"><a class="owl-video" href="https://www.youtube.com/watch?v=M7lc1UVf-VE"></a></div>
