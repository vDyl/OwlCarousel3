Setup

Enable navigation and choose one of the supported navPosition values.

Bottom (default)

Use bottom, or omit navPosition, to place the controls below the carousel.

$('.owl-carousel').owlCarousel({
	items: 3,
	loop: true,
	nav: true,
	navPosition: 'bottom'
})

Overlay

Use overlay to place the controls at the vertical center of the carousel edges.

$('.owl-carousel').owlCarousel({
	items: 3,
	loop: true,
	nav: true,
	navPosition: 'overlay'
})

Outside

Use outside to place the controls just beyond the carousel edges. Make sure the surrounding layout leaves enough horizontal space for the buttons.

$('.owl-carousel').owlCarousel({
	items: 3,
	loop: true,
	nav: true,
	navPosition: 'outside'
})

Without dots

The dots can be disabled with any navigation position:

$('.owl-carousel').owlCarousel({
	items: 3,
	loop: true,
	nav: true,
	navPosition: 'overlay',
	dots: false
})

The overlay styles are provided by owl.theme.default.css and owl.theme.green.css. They use the built-in navigation container. If you set navContainer, position that custom container in your own stylesheet instead.

Customize the control size and inset with CSS custom properties:

.owl-carousel {
	--owl-nav-size: 48px;
	--owl-nav-offset: 12px;
}

Navigation colors can also be styled at runtime. These properties apply to every navigation position:

.owl-carousel {
	--owl-nav-color: #fff;
	--owl-nav-background: #2d44b6;
	--owl-nav-color-hover: #fff;
	--owl-nav-background-hover: #ff3f4d;
}

Projects compiling the Sass theme can alternatively set $owl-nav-color, $owl-nav-background, $owl-nav-color-hover, and $owl-nav-background-hover before loading the theme module.
