Overview

The URLhashListener option listens for URL hash changes and selects the slide with the matching data-hash value, for example data-hash="zero".

The startPosition option also accepts 'URLHash'. This loads the corresponding item on startup. When URLhashListener:true, browser back and forward navigation also follows carousel hash changes.

Setup

	$('.owl-carousel').owlCarousel({
		loop:false,
		margin:10,
		URLhashListener:true,
		autoplayHoverPause:true,
		startPosition: 'URLHash'
	});
