Contributing

Owl Carousel 3 is community maintained. Special thanks go to the Owl Carousel 2 contributors whose work forms the foundation of this project.

To propose an improvement or bug fix, visit the GitHub project and fork the repository.

Some tips for contributors

Owl Carousel is built with npm, esbuild, Dart Sass, PostCSS, and Playwright.

Development requires Node.js 20.19 or later and npm.

Install dependencies

Open Terminal, go to folder with project and type:

npm install

Install Chromium for the browser test suite, then build and test the distribution:

npx playwright install chromium
npm run build
npm test

Source code is in src/. Documentation source is in docs_src/. Do not edit dist/ or docs/ directly; both are regenerated by npm run build.
