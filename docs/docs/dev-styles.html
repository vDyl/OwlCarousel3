Using Sass

Owl uses Dart Sass to build CSS for all main modules and themes. If you don’t know Sass, have a look at their website.

Building from source requires Node.js 20.19 or later and npm.

Run npm run build to compile the SCSS files, prefix the generated CSS, and create minified variants.

SCSS Files included

Source files can be found in the GitHub project.

src/
└── scss/
    ├── _animate.scss
    ├── _autoheight.scss
    ├── _core.scss
    ├── _lazyload.scss
    ├── _theme.scss
    ├── _theme.default.scss
    ├── _theme.green.scss
    ├── _video.scss
    ├── owl.carousel.scss
    ├── owl.theme.default.scss
    └── owl.theme.green.scss

Partial modules

Files beginning with _ are Sass modules used by the three public entry points. _core.scss contains the carousel layout, while _animate.scss, _autoheight.scss, _lazyload.scss, and _video.scss contain plugin styles.

_theme.scss

Shared structure for the default and green navigation themes. Configure _theme.default.scss or _theme.green.scss with Sass @use when creating a custom theme.

owl.carousel.scss

Public entry point that combines the core and plugin style modules.

owl.theme.*.scss

Generated theme entry points for navigation buttons and dots. For custom Sass configuration and examples, see BUILDING.md.
