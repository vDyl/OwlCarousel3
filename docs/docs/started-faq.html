FAQ

Read these common questions before opening an issue:

Can I use it for free or commercially?

Yes!

Yes. Owl Carousel 3 is available under the MIT License and may be used for personal and commercial projects.

Can I use multiple carousels on one page?

Yes. Initialize each matching carousel element with jQuery. As with any HTML, do not reuse the same id value on multiple elements.

Can I request a feature?

Yes. Open a feature request in GitHub Issues.

I need help!

Check the documentation and demos first. If the problem remains, open a GitHub issue with a minimal reproducible example and details about your browser and jQuery version.

Does it support continuous looping?

Yes. Set loop: true.

Where can I find release changes?

See the release notes on the GitHub releases page.
